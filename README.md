## General Information:
This source code belongs to a semi-official modded version of the hit game "Armchair Commander." With permission from the original developer (https://github.com/zack-sima), I am releasing this version to the public. You can find the change-log <a href="https://github.com/atlas1dev/armchair-commander-ee/blob/main/Changelog.txt">here.</a> An expanded wiki may become available in the future. The project will always be open-source, free of micro-transactions, and without intrusive advertisements. Please visit our <a href="https://discord.gg/EgMPUAV3Ze">Discord</a> for any questions or concerns.

Enjoy!
- Atlas1

## Technical:
- The latest version is 1.0 BETA.
- The mod was made in Unity version 6000.4.0f1.
- Contributions, bug-reports, translations, and tests are appreciated.
- The project was successfully tested on Fedora Linux and is also likely supported by most Debian-based distributions.
